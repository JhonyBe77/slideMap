# 🛰️ Banner Scroll con Geolocalización

Este proyecto es un banner interactivo con scroll horizontal que contiene:

- 🖼️ Una imagen promocional
- 📍 Un mapa dinámico con la ubicación del usuario

Perfecto para campañas que buscan **atraer tráfico a tiendas físicas** desde banners online.
